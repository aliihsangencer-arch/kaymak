# k-Koçluk

Eğitim koçları için öğrenci takip uygulaması: haftalık program, konu planı, kaynak ve test takibi, denemeler, veli raporu.

- `index.html` — uygulamanın tamamı (tek dosya)
- `supabase/` — veritabanı kurulum dosyaları (Supabase SQL Editor'de çalıştırılır)

Hesaplar yönetici onayıyla açılır; her koç yalnızca kendi kayıtlarını görür. Bu kurallar sunucuda (Supabase satır düzeyi güvenlik) uygulanır.
